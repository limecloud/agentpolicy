# Agent Policy v0.1.4

Agent Policy v0.1.4 is a patch release that aligns policy decisions, approvals, grants, waivers, redaction, retention, and traces with the Agent Runtime profile.

## Highlights

- Adds runtime profile test cases for runtime ids, risk scopes, decisions, ask/deny/allow mapping, grants, waivers, delegated approvals, redaction, and policy traces.
- Aligns interoperability guidance with Agent Runtime permission, action, sandbox, tool, evidence, and UI refs.
- Adds optional runtime correlation fields to the public event schema.
- Refreshes README, navigation, LLM entrypoints, release notes, package metadata, and version snapshots for v0.1.4.
