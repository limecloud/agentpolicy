# 术语表

| Term | 含义 |
| --- | --- |
| Agent Policy | Agent 动作的策略决策与 trace 事实标准。 |
| Policy decision | 对候选动作的策略评估结果。 |
| Subject | 请求动作的 actor：用户、Agent、服务、子 Agent 或会话。 |
| Action | 工具调用、模型调用、导出、记忆写入、委托等候选操作。 |
| Resource | 文件、URL、Artifact、来源、模型、工具、凭证或 peer。 |
| Context | 用于评估的事实：模式、信任边界、敏感度、时间、成本、租户与 refs。 |
| Risk scope | 动作影响的风险边界。 |
| Obligation | 附着在决策上的强制职责。 |
| Advice | 附着在决策上的非强制建议。 |
| Approval request | 审批或升级请求。 |
| Permission grant | 策略评估或审批后发出的有界能力。 |
| Waiver | 对策略阻断的显式有界覆盖。 |
| Policy trace | 连接输入、规则、决策、审批、grant、waiver、runtime、telemetry 与 evidence 的关联图。 |
