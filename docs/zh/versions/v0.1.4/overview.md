# Agent Policy v0.1.4

Agent Policy v0.1.4 是 patch release，用于把 policy decisions、approvals、grants、waivers、redaction、retention 与 traces 对齐 Agent Runtime profile。

## 重点

- 新增 runtime profile 测试用例，覆盖 runtime ids、risk scopes、decisions、ask/deny/allow mapping、grants、waivers、delegated approvals、redaction 与 policy traces。
- 将互操作指南对齐 Agent Runtime permission、action、sandbox、tool、evidence 与 UI refs。
- 在公共 event schema 中加入可选 runtime correlation 字段。
- 刷新 README、导航、LLM entrypoints、release notes、package metadata 与 v0.1.4 版本快照。
