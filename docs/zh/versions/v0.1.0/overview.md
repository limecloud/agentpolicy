# v0.1.0 概览

Agent Policy v0.1.0 是第一个公开草案，定义 Agent policy exchange 所需的 decision、approval、grant、risk、waiver、trace、redaction、retention 与 interoperability vocabulary。

## Included

- `policy_decision` core envelope。
- `risk_scope` vocabulary。
- `approval_request` 与 `permission_grant` contracts。
- redaction 与 retention obligations。
- `waiver_record` 与 `policy_trace` contracts。
- event classes 与 JSON Schemas。
- 中英文文档。
- LLM-friendly `llms.txt` 与 `llms-full.txt`。
